# PC 全般の便利ツール・設定

ターミナルやシェルの設定とは少し離れて、この章では **Windows の OS 設定**や **Chrome 拡張機能**など、PC 操作全般を快適にするためのツール・設定をまとめます。今後も便利な Tips を随時追加していく章です。

## Windows

### 仮想デスクトップのスライドアニメーション無効化

Windows の仮想デスクトップを `Win + Ctrl + ←/→` で切り替えると、大きなスライドアニメーションが発生します。画面全体が動くため、認知負荷が高く感じる場合があります。

参考: [【Windows10,11】仮想デスクトップ間のスライドアニメーションの設定](https://zenn.dev/takashiaihara/articles/a1dfc9899a5fe7)

#### Windows 10 での設定方法

1. `Win + R` → `sysdm.cpl` を実行してシステムのプロパティを開く
2. 「詳細設定」タブ → 「パフォーマンス」の「設定」をクリック
3. 「ウインドウを最大化や最小化するときにアニメーションで表示する」をオフにする

#### Windows 11 (22H2) での設定方法

1. 設定 → アクセシビリティ → 視覚効果
2. 「Windows 内のアニメーション コントロールと要素」をオフにする

:::message
Windows 10 と Windows 11 では、同じ項目名でもアニメーションの挙動が異なる場合があります。また、この設定は他のアニメーション（ウィンドウの最大化・最小化など）にも影響することがあります。
:::

## Chrome 拡張機能

### Vimium — キーボードだけでブラウザを操作する

**Vimium** は、Vim のキーバインドで Chrome を操作できる拡張機能です。マウスをほとんど使わずにブラウジングできるため、開発者や Vim ユーザーに特におすすめです。

参考: [Vimium を使って Chrome を Vim のように操作する方法](https://qiita.com/arihori13/items/19ff042ecca5c3b0b2c4)

#### インストール

Chrome Web Store から「Vimium」を検索し、「Chrome に追加」→「拡張機能を追加」でインストールできます。

#### 主要コマンド

| 操作           | キー | 説明                                 |
| -------------- | ---- | ------------------------------------ |
| スクロール下   | `j`  | 少し下にスクロール                   |
| スクロール上   | `k`  | 少し上にスクロール                   |
| ページ先頭     | `gg` | ページの一番上に移動                 |
| ページ末尾     | `G`  | ページの一番下に移動                 |
| 新しいタブ     | `t`  | 新しいタブを開く                     |
| タブを閉じる   | `x`  | 現在のタブを閉じる                   |
| 前のタブ       | `J`  | 左のタブに移動                       |
| 次のタブ       | `K`  | 右のタブに移動                       |
| ページ内検索   | `/`  | 検索モードに入る（`n` で次の一致へ） |
| リンクを開く   | `f`  | 現在のタブでリンクを選択して開く     |
| 新タブでリンク | `F`  | 新しいタブでリンクを選択して開く     |

#### 設定のカスタマイズ

拡張機能のオプション画面から以下をカスタマイズできます。

- **Excluded URLs**: 特定のサイト（例: Google Docs、Notion など入力が多いサービス）で Vimium を無効にする
- **Custom key mappings**: ショートカットキーを自分好みに変更する
- **Custom search engines**: 独自の検索エンジンを登録する（例: GitHub 検索を `gh <keyword>` で呼び出す）
